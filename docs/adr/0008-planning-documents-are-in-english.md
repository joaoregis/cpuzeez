# ADR 0008: Planning documents are in English

- **Status:** accepted (2026-11-04)
- **Decision ref:** Q8 · details in [docs/v1/README.md](../../docs/v1/README.md#8-decisions)

## Context
The repository is public and contributors are international.

## Decision
Design docs, ADRs and code comments are written in English. User-facing text keeps its translations (pt-BR, es) and README.pt-BR.

## Alternatives considered
Portuguese-only docs.
