Code signing policy

Status: Windows releases are not signed yet. CPU ZeeZ has applied to the SignPath Foundation's free code signing program for open-source projects. This page will say when signed releases start.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only files built from this repository's source: cpuzeez.exe, the MSI installer and the portable zip of each release. Every release is built by GitHub Actions from a tagged commit on main; nothing built on a personal computer is signed. Third-party programs shipped with the app (Intel's PresentMon, the PawnIO driver and its modules) keep their own publishers' signatures and are not signed by this project.

Team roles

  • Authors (commit without further review): @joaoregis, the owner.
  • Reviewers (review every change from anyone else, such as a pull request, before it is merged): @joaoregis.
  • Approvers (approve each signing request by hand, for a release tag only): @joaoregis.

Everyone with these roles uses multi-factor authentication on GitHub and on SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

In detail: there is no telemetry and no account. The only network request the app makes on its own is the update check, which is off until you turn it on; it asks GitHub's public API for the latest release and, when you choose to update, downloads that release from GitHub. Everything else the app records (app history, captures, benchmark results, the action log) stays on your computer.

Third-party components shipped with the app make no network requests of their own: Intel's PresentMon reads frame timing from the local system, and the PawnIO driver reads hardware registers. CPU ZeeZ also changes system settings only when you ask (ending a process, a service's startup type, a startup item), warns before risky ones, and the installers uninstall cleanly.

Reporting a problem

If you find a signed file that this policy does not cover, or a security problem, follow the security policy.
